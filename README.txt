EDU Genie - Google Gemini Powered Learning Assistant

Files:
1. index.html - Main webpage
2. style.css - Website design
3. script.js - Frontend functionality
4. server.js - Backend server
5. package.json - Node.js configuration

To run:
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open Terminal.
4. Run: npm install
5. Run: npm start
6. Open index.html in a browser.

The server.js file contains the location where Google Gemini /
Google Cloud Generative AI can be connected.
